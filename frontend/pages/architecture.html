💻 Tier 1: Client Edge AI

ประมวลผลโมเดล MediaPipe Pose (33 จุด) บนเบราว์เซอร์ผ่าน WASM/WebGL 60 FPS ปราศจากการส่งภาพวิดีโอเข้าเซิร์ฟเวอร์ รักษาความเป็นส่วนตัวสูงสุด (Privacy-First)

WASM • WebGL • Zero Video Upload

🌐 Tier 2: API Gateway & Static

ทำหน้าที่ Reverse Proxy และจัดการ CORS ควบคุมการกระจายคำขอไปยัง Microservices พร้อมทั้งทำหน้าที่แคชและแจกจ่ายไฟล์ Static (HTML, CSS, JS และภาพ GIF ท่าตัวอย่าง)

Apache 2.4 • Nginx • Reverse Proxy

⚙️ Tier 3: Core Microservices

บริการ FastAPI แบบ Asynchronous ทำงานแยกโมดูลอย่างเป็นอิสระ (Auth, User Profile, Workout Routine, Score Verification, Leaderboard และ Admin)

Python 3.10+ • FastAPI • JWT Auth

🗄️ Tier 4: Data Persistence

รองรับฐานข้อมูลหลักทั้ง MariaDB/MySQL 8.0 (XAMPP) และ PostgreSQL 15 (Docker) พร้อมการเชื่อมต่อผ่าน SQLAlchemy Connection Pooling เพื่อรองรับ Concurrency สูง

MySQL • PostgreSQL • SQLAlchemy

📋 3. Technical Specification Table
เลเยอร์ (Layer) เทคโนโลยี / เครื่องมือ บทบาทและวัตถุประสงค์ในระบบ
1. Frontend UI HTML5, Vanilla CSS3, ES6+ JS โครงสร้างหน้าเว็บดีไซน์ Clean Modern Light Theme โหลดเร็ว ไร้ Overhead เฟรมเวิร์ก เพื่อความเร็วสูงสุด
2. Edge Vision AI Google MediaPipe Pose, WASM, WebGL ตรวจจับโครงสร้างร่างกาย 33 จุดแบบ Real-time 60 FPS บน Browser โดยตรง ไม่ส่งภาพวิดีโอเข้าเซิร์ฟเวอร์
3. Audio & Graphics Web Audio API, Canvas 2D API สังเคราะห์เสียง Beep/Countdown ไร้ไฟล์ mp3 และวาดเส้นโครงกระดูกเรืองแสงตอบสนองความแม่นยำของฟอร์ม
4. Web Server / Gateway Apache HTTP Server / Uvicorn ASGI ให้บริการ Static Assets (HTML, CSS, JS, GIFs) และทำหน้าที่ Reverse Proxy ไปยัง Python Backend API
5. Backend Framework Python 3.10+, FastAPI, Pydantic v2 บริการ Microservices API แบบ High-performance Asynchronous รองรับ Non-blocking I/O และ Validate ข้อมูล
6. Security & Auth PyJWT, Passlib (Bcrypt) ระบบยืนยันตัวตนด้วย Stateless JWT Tokens และเข้ารหัสผ่านผู้ใช้ด้วย Salted Bcrypt ปลอดภัยตามมาตรฐาน
7. Persistence & ORM SQLAlchemy, MySQL / MariaDB, PostgreSQL เชื่อมต่อฐานข้อมูลด้วย Connection Pooling รองรับทั้ง MariaDB บน XAMPP และ PostgreSQL บน Docker
8. Database Admin phpMyAdmin Web GUI หน้าจอเว็บสำหรับจัดการฐานข้อมูล ดูและแก้ไขตาราง users, scores ได้สะดวกรวดเร็ว
9. DevOps & Containers Docker, Docker Compose, Git จัดการสภาพแวดล้อมจำลอง (Containerization) รวม FastAPI, PostgreSQL และ phpMyAdmin ในคำสั่งเดียว
🔄 4. Privacy-First Edge Data Flow

👤 1. Ingestion Profile

ผู้ใช้ล็อกอิน ระบบเรียก GET /api/users/{id} ดึงค่าน้ำหนักและส่วนสูงมาคำนวณ BMI และส่งต่อไปยัง MET Calorie Tracker อัตโนมัติ

⚡ 2. Edge Processing

วิดีโอจากกล้องถูกประมวลผลบนเครื่อง (Client WASM) เพื่อหามุมข้อต่อและนับ Reps ไม่มีการส่งภาพออกจากเครื่องแม้แต่เฟรมเดียว

📊 3. Score Sync

เมื่อออกกำลังกายเสร็จสิ้น ระบบส่งสถิติรวม (แคลอรี่, ความแม่นยำ, ระยะเวลา) ไปยัง POST /api/scores/submit เพื่อบันทึกและขึ้น Leaderboard

🎯

ผลการประเมินประสิทธิภาพในสัปดาห์นี้ (Weekly Finding)

"ส่วนหน้า (UI/UX) และระบบฐานข้อมูลทำงานได้อย่างสมบูรณ์และเสถียร แต่ผลการทดสอบการตรวจจับท่าทางผ่านกล้องและโมเดล AI (MediaPipe Pose) ยังไม่ค่อยแม่นยำ"

🔍 สาเหตุหลัก 4 ประการที่ทำให้โมเดลยังไม่แม่นยำ:
  1. ขอบเขตมุมมองกล้อง (Camera FOV & Distance): กล้องเว็บแคมมีมุมมองแคบ เมื่อผู้ใช้ยืนใกล้เกินไป ข้อเท้าหรือหัวเข่าจะหลุดเฟรม ทำให้ AI พยายามคาดเดาตำแหน่งผิดพลาด ส่งผลต่อการนับ Squats / High Knees
  2. แสงสว่างและฉากหลังรบกวน (Lighting & Background Clutter): ในสภาพแสงน้อยหรือแสงย้อน คอนทราสต์ต่ำ ทำให้จุด Landmark มีอาการสั่น (Jitter) ส่งผลให้การคำนวณมุมข้อต่อกระโดด
  3. ภาพเบลอจากการขยับเร็ว (Motion Blur): ในท่าที่ขยับไว เช่น กระโดดตบ (Jumping Jacks) อัตราจับภาพกล้องไม่ทัน ทำให้ AI หลุดเฟรมจุดพีก (Peak Extension)
  4. เฟรมเรตตกบนอุปกรณ์ที่ไม่มี GPU Acceleration: อัตราประมวลผลลดจาก 60 FPS เหลือ 15–20 FPS ทำให้การจับการเคลื่อนไหวขาดช่วง
