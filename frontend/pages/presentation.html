RESPONSIVE GRID & THAI TYPOGRAPHY ARCHITECTURE

การแก้ปัญหาโครงสร้าง Layout, การกระจายคอลัมน์อัตโนมัติ และการแก้ปัญหาตัดคำภาษาไทย

1. Dynamic Container Queries (4 / 3 / 1 คอลัมน์)

จัดสัดส่วนอัตโนมัติตามขนาดคอนเทนเนอร์จริง: จอใหญ่ (≥1000px): 4 คอลัมน์ | จอกลาง (680-999px): 3 คอลัมน์ | จอมือถือ (<680px): 1 คอลัมน์เต็มความกว้าง 100%

2. Smart Sandbox Card Layout (ขยายกิน 2 คอลัมน์)

ย้ายการ์ด Sandbox (คอร์สจัดเอง) ลงไว้ล่างสุดของรายการคอร์ส และตั้งค่าให้ขยายกินพื้นที่ 2 คอลัมน์บนจอขนาดกลาง เพื่อเติมเต็มพื้นที่ว่าง ไม่ให้เกิดช่องโหว่ใน Grid

3. Thai Typography Word-Break Fix (แก้สระ/อักษรตกบรรทัดแนวตั้ง)

แทนที่ word-break: break-word ด้วย overflow-wrap: break-word; word-break: normal; ร่วมกับ align-items: stretch ป้องกันการบีบกล่องจนตัวอักษรไทยเรียงเป็นแนวตั้ง

4. PRO UI Suppression (ซ่อนปุ่มอัปเกรดเมื่อเป็น PRO)

ตรวจจับสถานะ is_pro ตรงจาก Database หากเป็น PRO จะสั่งซ่อนปุ่มอัปเกรดทั้งหมดตั้งแต่โหลดใน <head> ป้องกันการกระพริบของหน้าจอ

NEW AI POSE: PUSH-UP BIOMECHANICAL ANALYSIS

ขยายขีดความสามารถการตรวจจับจากท่ายืน สู่ระนาบแนวนอนด้วยเวกเตอร์ชีวกลศาสตร์แบบ On-Device 60 FPS

1. Elbow Angle Vector Tracking (วัดมุมข้อศอก ≤ 90°)

คำนวณมุมสามเหลี่ยม Shoulder (11) → Elbow (13) → Wrist (15) ต้องลงลึก ≤ 90° เพื่อให้นับว่าผ่าน Rep และต้องดันแขนเหยียดสุด ≥ 155° เมื่อขึ้นสุด

2. Torso Alignment Verification (ตรวจสอบแนวลำตัวตรง 180°)

ตรวจสอบแกนลำตัว Shoulder (11) → Hip (23) → Ankle (27) ป้องกันหลังแอ่นหรือสะโพกโด่งเกินมุมที่ถูกต้อง พร้อมส่งเสียงแจ้งเตือนแบบเรียลไทม์

3. Anti-Cheat Finite State Machine (ป้องกันการนับซ้ำ/โกง)

ควบคุมลำดับการขยับ 5 ขั้น: UP → GOING_DOWN → BOTTOM → ASCENDING → COUNTED นับรอบเฉพาะเมื่อฟอร์มถูกต้องครบวงจร
